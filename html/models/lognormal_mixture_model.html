LognormalMixtureModel

LognormalMixtureModel(F, T, r=0.0)
Two-component lognormal mixture model for a single maturity. Parameters ---------- F : float Market forward price. T : float Time to maturity. r : float Continuously compounded risk-free rate. Model parameters ---------------- p : float Weight of first component. displacement : float Determines F1 through F1 = F * exp(displacement). sigma1 : float Volatility of first component. sigma2 : float Volatility of second component. The second component forward F2 is determined by p F1 + (1-p) F2 = F so that the mixture satisfies the risk-neutral forward condition.
