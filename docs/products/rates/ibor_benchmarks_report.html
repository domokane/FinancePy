benchmarks_report

benchmarks_report( benchmarks, value_dt: Date, discount_curve: DiscountCurve, index_curve: DiscountCurve = None, include_objects = False, )
Generate a DataFrame with one row per benchmark. A benchmark is any object that has a function valuation_details(...) that returns a dictionary of the right shape. Allowed benchmarks at the moment are depos, fras and swaps. Various useful information is reported. This is a bit slow so do not use in performance-critical spots
