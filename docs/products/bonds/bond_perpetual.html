BondPerpetual( issue_dt: Date, coupon: float, freq_type: FrequencyTypes, accrual_dc_type: DayCountTypes = <DayCountTypes.ACT_ACT_ICMA: 6>, first_coupon_dt: Date | None = None, ex_div_days: int = 0, cal_type: CalendarTypes = <CalendarTypes.WEEKEND: 2>, bd_type: BusDayAdjustTypes = <BusDayAdjustTypes.FOLLOWING: 2>, ) -> None
Inherits from: Product
Class for perpetual bonds (Consols / undated debt). These instruments have regular periodic coupon payments of a known rate and have no maturity date (T = infinity). The principal is never repaid.

dirty_price_from_discount_curve( self, settle_dt: Date, discount_curve: DiscountCurve, horizon_years: float = 100.0, ) -> float
Calculate the dirty price of the perpetual bond from an arbitrary discount curve. Coupons falling within horizon_years of settlement are discounted off the curve one by one. The perpetuity beyond the horizon is valued as a tail that continues the curve's forward rate over the final coupon period, so a sloped curve is not truncated at a spot rate.
