Interpolator

Interpolator(interpolator_type: 'InterpTypes', **kwargs: 'dict')
Discount-factor interpolator. The class separates fitting from evaluation: * ``fit`` validates and stores the market knots, and builds any expensive spline representation once. * ``interpolate`` performs the cheapest possible evaluation path for the selected interpolation type.
